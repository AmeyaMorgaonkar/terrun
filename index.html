Discrete Math Project

Territory Fitness is a discrete mathematics course demonstration project integrating:

  • Propositional Logic: Real-time 4-variable Boolean capture truth tables.
  • Set Theory: Formal sets M, R, M ∪ R, M ∩ R, contested frontier, and live Inclusion–Exclusion proof.
  • Graph Theory: Dijkstra shortest path on synthetic street network with binary min-heap; 4-neighbor BFS connected components.
  • Combinatorics: Monotone lattice paths C(n, k) & DAG Dynamic Programming path counting.
  • Topology & Planar Graphs: Jordan Curve theorem flood fill enclosure; Handshake lemma proof ∑ deg(v) = 2|E|.
  • Modular Arithmetic: Prime modulo-997 hash codes and 2D mod-3 tessellation.
Local Storage Note: User accounts, runs and grid states are stored locally on this device in browser localStorage. No data is sent to external servers.
